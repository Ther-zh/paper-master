# 模块9：引用验证与格式化

> 来源吸收：citation-verifier（42 installs，引用类最高）+ citation-finder（32 installs）+ citation-formatter（32 installs）+ nature-citation（832 downloads）

## 触发关键词
引用检查、引用验证、citation check、DOI 验证、参考文献、bibliography、BibTeX、引用格式、citation format、引用是否真实、引用格式化

## 工作流

### 阶段1：引用完整性检查

#### 1.1 引用存在性验证
对论文中每个 `\cite{}` 执行：
- [ ] 引用条目在 .bib 文件中存在？
- [ ] .bib 条目包含所有必填字段？（author, title, year, journal/booktitle, DOI）
- [ ] 无反斜杠转义错误？

#### 1.2 DOI 真实性验证
对每个有 DOI 的引用：
- [ ] DOI 格式正确？（`10.xxxx/xxxx`）
- [ ] DOI 可解析？（通过 doi.org/api 验证）
- [ ] 作者/标题/年份与 .bib 一致？
- [ ] 会议/期刊名称与 .bib 一致？

#### 1.3 引用一致性检查
- [ ] 同一论文在正文中引用格式一致？（如作者-年份 vs 编号）
- [ ] 同一作者的引用前后名字拼写一致？
- [ ] 会议/期刊缩写是否统一？

### 阶段2：引用真实性评估

#### 2.1 高风险信号
- 通过搜索引擎/学术数据库无法找到该论文
- DOI 无法解析或指向不同论文
- 标题看似合理但与知名工作过于相似
- 作者列表不可能（如全部为知名作者但从未合作过）
- 期刊/会议在那一年不存在

#### 2.2 可疑引用处理
```
[⚠️ 可疑引用] Liu et al., 2023
  问题：DOI 10.1000/xxxxx 无法解析
  建议：手动确认该引用是否真实存在
  操作：标记为待验证，不直接删除
```

### 阶段3：引用格式适配

#### 3.1 格式检测
自动检测论文使用的引用格式：
- `[1]` 编号式（IEEE, ACM）
- `(Author, Year)` 作者-年份式（APA, Harvard）
- `[ABC23]` 缩略编号式（部分 CS 会议）
- 上标编号式（部分中文期刊）

#### 3.2 格式修复
- [ ] 所有引用格式统一？
- [ ] BibTeX entry type 与引用用途匹配？（`@article` vs `@inproceedings` vs `@misc`）
- [ ] 标题中不应大写的词是否正确？（LaTeX `{}` 保护）
- [ ] 作者名的 "and" 分隔是否正确？

#### 3.3 跨期刊格式转换
支持常见格式转换：
- IEEE → APA
- ACM → Harvard
- 编号式 → 作者-年份式
- Nature → arXiv

### 阶段4：引用合理性检查

- [ ] **自引比例**：自引是否过多？（>30% 需标注）
- [ ] **时效性**：近3年引用占比？（推荐 >40%）
- [ ] **覆盖性**：是否遗漏了该领域的经典/必引工作？
- [ ] **挂名引用**：是否存在与内容无关的引用？
- [ ] **二手引用**：是否引用了二手来源而非原始论文？

### 阶段5：BibTeX 文件维护

- [ ] 所有 .bib 条目按字母顺序排列？
- [ ] 所有条目使用统一的 citation key 格式？（推荐 `authorYYYYkeyword`）
- [ ] 清理未使用的 .bib 条目？
- [ ] 补全缺失字段的条目？

## 输出格式

```
## 引用验证报告

### 统计数据
- 总引用数：X
- 通过验证：X
- 需要修正：X（列出具体问题和建议）
- 可疑引用：X（标注风险等级）

### 详细问题列表
| 引用 | 问题类型 | 严重程度 | 修正建议 |
|------|---------|---------|---------|
| \cite{smith2020} | DOI 不可解析 | ⚠️ 高 | 手动确认 |

### 格式修正建议
- 引用格式不一致：3处
- 建议统一为：[格式]

### 引用合理性评估
- 自引比例：X%
- 近3年引用：X%
- 缺失推荐引用：Y
```
