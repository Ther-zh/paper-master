# 模块11：论文翻译

> 来源吸收：arxiv-translator（426⭐，Leey21）+ nature-reader（829 downloads）+ arxiv-translator 双语阅读模式

## 触发关键词
翻译、中译英、英译中、论文翻译、translate、translation、双语、逐段翻译、润色翻译、polish after translation

## 工作流

### 阶段1：翻译策略选择

| 场景 | 推荐策略 | 说明 |
|------|---------|------|
| 中文论文→英文投稿 | 翻译 + 学术润色 | 先翻译再调用模块2润色 |
| 英文论文→中文理解 | 双语对照翻译 | 原文与译文对照，保留术语 |
| arXiv 论文阅读 | 快速翻译 | 仅翻译关键段落（摘要/引言/结论） |
| 学术交流 | 术语一致翻译 | 确保领域术语翻译规范 |

### 阶段2：逐段翻译流程

#### 2.1 预处理
- [ ] 识别 LaTeX 命令/数学公式（不可翻译）
- [ ] 识别 `\cite{}`、`\ref{}`（保留原样）
- [ ] 识别图表标题
- [ ] 分割为独立段落

#### 2.2 逐段翻译（一段一消息）
```
原文段落 → 
  [翻译] 直译（忠实原文） → 
  [润色] 学术化改写（调用模块2） → 
  [校验] 检查翻译是否偏离原意
```

#### 2.3 术语一致性维护
- 首次出现术语：`术语（English Term）`
- 后续出现：中文术语或英文标准术语
- 维护术语表（每篇论文一份）：

| 中文术语 | 英文术语 | 领域 |
|---------|---------|------|
| 注意力机制 | Attention Mechanism | ML |
| 梯度下降 | Gradient Descent | ML |

### 阶段3：中译英特殊规则

#### 3.1 句式转换
- 中文多短句 → 英文需用连接词合并
- 中文无主语句 → 补充主语或转被动
- 中文"被"字句 → 英文被动语态需谨慎使用
- 中文双否定 → 简化为肯定句

#### 3.2 学术英文规范
- 避免 `I/we think/believe` → `We argue/hypothesize/suggest`
- 避免口语化表达（`a lot of` → `many/significant`）
- 统一时态：相关工作用现在时，实验用过去时
- 段落首句明确中心思想（呼应模块2 的段落原则）

#### 3.3 常见中式英语陷阱

| 中式表达 | 错误英文 | 正确英文 |
|---------|---------|---------|
| 在...情况下 | Under...situation | In...case / When... |
| 通过...方法 | Through...method | Using/By/With...approach |
| 扮演重要角色 | Play an important role | Is central/key to... |
| 引起了广泛关注 | Caused wide attention | Has attracted significant attention |

### 阶段4：英译中特殊规则

#### 4.1 翻译深度选择
- **快速模式**：仅翻译摘要 + 引言 + 结论（10分钟了解论文）
- **完整模式**：全文翻译 + 方法细节保留
- **双语模式**：原文与译文对照输出（推荐用于精读）

#### 4.2 术语处理
- 专业术语保留英文（如 ReLU、LSTM）
- 首译给出全称 + 缩写
- 避免生硬直译（如 `convolutional neural network` → 「卷积神经网络」而非「卷曲式神经网路」）

### 阶段5：翻译质量检查

- [ ] 数学公式/LaTeX 命令是否完整保留？
- [ ] `\cite{}` `\ref{}` 是否未被翻译？
- [ ] 术语翻译是否前后一致？
- [ ] 译文是否流畅可读（而非机器翻译感）？
- [ ] 图表标题是否翻译了？
- [ ] 是否有明显的漏译段落？

## 输出格式

```
## 翻译报告

### 翻译统计
- 总字数：X
- 翻译段落数：X
- 术语数：X

### 术语表
| 中文 | 英文 | 首现段落 |

### 翻译稿
（带原文对照或独立译文）

### 质量评估
- 机器翻译感评分：1-10（10为完全自然）
- 建议人工复核段落：X
```

## 与相关模块协作

- → 模块2（段落润色）：翻译后自动调用润色（中译英场景）
- → 模块3（LaTeX精修）：翻译涉及 LaTeX 源码时配合检查
- → 模块6（去AI痕迹）：翻译稿需通过 AI 检测
