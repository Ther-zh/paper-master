# 模块10：学位论文写作

> 来源吸收：dissertation-workflow-core（29 installs，学位论文类最高）+ thesis-writing-advisor（14 installs）

## 触发关键词
学位论文、硕士论文、博士论文、thesis、dissertation、硕士、博士、开题报告、中期检查、盲审、答辩、毕业论文、大论文

## 学位论文 vs 期刊论文差异

| 维度 | 期刊/会议论文 | 学位论文 |
|------|-------------|---------|
| 篇幅 | 8-12 页 | 50-150 页 |
| 贡献要求 | 1-2 个创新点 | 系统性工作（3+ 贡献点） |
| 读者 | 领域同行 | 答辩委员会 + 领域同行 |
| 结构 | IMRAD | 章节制（5-7 章） |
| 文献综述 | 1-2 页 Related Work | 独立章节（15-30 页） |
| 实验细节 | 简要描述 | 完整附录 |
| 写作时间 | 2-8 周 | 3-12 个月 |

## 工作流

### 阶段1：开题报告

#### 1.1 选题确认
- [ ] 研究问题明确且有价值？
- [ ] 与导师达成共识？
- [ ] 文献调研显示有创新空间？

#### 1.2 开题报告结构
```
1. 研究背景与意义（1-2页）
2. 国内外研究现状（3-5页）→ 调用模块8
3. 研究目标与内容（1-2页）
4. 研究方法与技术路线（1-2页）
5. 预期成果与创新点（0.5-1页）
6. 研究计划与时间安排（0.5页）
7. 参考文献
```

### 阶段2：论文结构规划

#### 2.1 推荐章节结构（博士论文）

```
第一章：绪论
  1.1 研究背景
  1.2 国内外研究现状 → 调用模块8
  1.3 现有工作的不足
  1.4 本文的研究内容与贡献
  1.5 论文组织架构

第二章：相关工作（深度综述）
  2.1 子方向A
  2.2 子方向B
  2.3 子方向C
  2.4 本章小结

第三章-第五章：核心贡献（3个主要工作）
  每章按：引言 → 方法 → 实验 → 讨论 → 本章小结

第六章：总结与展望
  6.1 工作总结
  6.2 未来工作

附录：实验细节/证明/额外结果
```

#### 2.2 每章写作流程
1. 先写本章大纲（1页内）
2. 与导师确认方向
3. 先写方法和实验（最容易）
4. 再写引言和讨论（最难）
5. 最后写本章小结

### 阶段3：逐章写作

#### 3.1 章节一致性检查
- [ ] 每章的引言都提到了与前后章节的关系？
- [ ] 符号定义在各章之间是否一致？
- [ ] 引用格式全篇统一？
- [ ] 图表编号连续且交叉引用正确？
- [ ] 术语全篇统一？

#### 3.2 篇幅控制
- 绪论：10-15 页
- 相关工作：15-30 页
- 核心贡献（每章）：15-25 页
- 总结：3-5 页
- 参考文献：5-10 页

### 阶段4：盲审准备

#### 4.1 格式要求（各校不同，下列为通用）
- [ ] 页边距：左3cm，右2.5cm，上下2.5cm
- [ ] 字体：正文小四宋体/Times New Roman，标题黑体
- [ ] 行距：1.5 倍行距
- [ ] 图表标题：五号黑体
- [ ] 参考文献格式：GB/T 7714（中文）/ APA（英文）

#### 4.2 匿名化检查
- [ ] 论文中无作者姓名
- [ ] 论文中无导师姓名
- [ ] 致谢部分移除或不提交
- [ ] 论文中无学校名称（可识别信息）
- [ ] 已发表论文的引用是否暴露了作者身份？

#### 4.3 盲审常见评审维度
| 评审点 | 要求 |
|--------|------|
| 选题意义 | 有理论或应用价值 |
| 文献综述 | 全面、有分析、非罗列 |
| 研究方法 | 科学、合理、可复现 |
| 创新性 | 在理论/方法/应用上有创新 |
| 论文写作 | 逻辑清晰、语言通顺、图表规范 |
| 工作量 | 饱满（博士>3年、硕士>1年） |

### 阶段5：答辩准备

#### 5.1 PPT 结构（20-30分钟）
```
1. 封面（1页）
2. 研究背景与动机（2-3页）
3. 研究问题（1页）
4. 核心工作1（4-5页）
5. 核心工作2（4-5页）
6. 核心工作3（4-5页）
7. 贡献总结（1页）
8. 发表论文列表（1页）
9. 致谢（1页）
```

#### 5.2 答辩预演清单
- [ ] 时间控制在要求范围内？
- [ ] 每页PPT能在1-2分钟内讲清？
- [ ] 核心贡献突出了"我做了什么"vs"已有工作"？
- [ ] 准备了可能被问的问题及答案？
- [ ] 准备了备选幻灯片（应对深度追问）？

## 输出格式

```
## 论文写作规划

### 整体结构（章节大纲）
### 时间规划（甘特图）
### 当前进度

## 逐章反馈
（每次聚焦一章，输出详细建议）

## 盲审检查报告
（按阶段4清单项检查）
```
